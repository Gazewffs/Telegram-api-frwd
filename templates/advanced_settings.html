Advanced Settings Explained
Session Path

This is where your Telegram session data is stored. The session file contains your authentication information, so you don't have to login every time.

Check Interval

How often the bot checks for new messages in source channels. A lower value means faster forwarding but might hit rate limits sooner.

Message Age

Only messages newer than this will be processed. Older messages are ignored to prevent forwarding historical content.

Rate Limiting

Telegram has rate limits for API calls. If you set intervals too low or have many channels, you might hit these limits.

Performance Tip

For most users, the default settings work well. Only change these if you have specific requirements.
