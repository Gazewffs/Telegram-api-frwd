Path to the image file that will replace all images when "Replace All Images" is enabled.
Relative paths are based on the application directory.
Format: image_hash:replacement_path,image_hash2:replacement_path2
Example: 1a2b3c4d5e6f7g8h:images/custom1.jpg,8h7g6f5e4d3c2b1a:images/custom2.jpg
To get the hash of an image, run the bot and check the logs when processing the image.
Help
Media Processing Options
Replace All Images

When enabled, all images in forwarded messages will be replaced with the default replacement image. This is useful if you want to avoid copyright issues or remove watermarks from all images.

Specific Image Replacements

This allows you to replace only specific images based on their hash. The bot calculates a hash for each image and compares it to your list of replacements.

How to Get Image Hashes

Start the bot with verbose logging enabled, then check the logs for media hash values when messages with images are processed.

Note

Make sure the replacement image files exist in the specified paths before enabling these features.

Supported Image Formats

JPEG, PNG, GIF, WebP, and other formats supported by Telegram.
