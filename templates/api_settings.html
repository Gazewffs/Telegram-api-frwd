How to Get API Credentials
  1. Go to my.telegram.org/apps and log in with your Telegram account.
  2. Fill out the form to create a new application if you don't have one already.
  3. Once created, you'll see your API ID and API Hash. Copy these values.
  4. Enter the values in the form on the left.
Important Security Note

Keep your API ID and API Hash private. Do not share them with others.

First-time Authentication

When starting the bot for the first time, you'll need to enter a verification code sent to your Telegram account.
